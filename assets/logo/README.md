# Roots logo

Lettered wordmark, lowercase "roots", one stroke weight. The two o's interlock like rings: each has a narrow break, curved to follow the ring passing over it, so the weave reads without a background-colored halo and the logo works on any background. The t's stem drops below the baseline into a gold root; the baseline is the ground line.

| File | Use |

| `roots-icon-180.png` | Apple touch icon (home screen on iPhone) |
| `roots-icon-small.svg`, `/favicon.svg`, `favicon-32.png`, `favicon-16.png` | Browser tab |

Below about 100 px wide, the wordmark's breaks close up and the oo reads as overlapping rings. That's expected; use the icon when space is that tight.

## Palette: Forest and gilt

| Role | Hex |
|---|---|
| Paper (light background) | `#EEEBE3` |
| Ink (on paper) | `#1D2B24` |
| Gilt (accent on paper) | `#A9822F` |
| Forest (dark background) | `#17241E` |
| Forest raised (tiles, cards on dark) | `#23362C` |
| Bone (ink on forest) | `#E8E2D2` |
| Gilt light (accent on forest) | `#C9A35A` |

Gilt is for graphic accents (the root, small marks), not body text: on paper it is below text contrast.
